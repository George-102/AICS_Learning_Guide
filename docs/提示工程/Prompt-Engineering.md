# 提示工程

## 课程简介

- 来源：DAIR.AI 发起的开源项目 Prompt Engineering Guide（[中文站点](https://www.promptingguide.ai/zh)、[英文站点](https://www.promptingguide.ai/)），以在线文档形式持续更新，配套维护 [GitHub 仓库](https://github.com/dair-ai/Prompt-Engineering-Guide)
- 先修要求：无需机器学习背景，能正常使用任意一款大语言模型（ChatGPT、Claude、Gemini、Kimi、DeepSeek 等）即可入门；读“模型”“研究论文”部分时，具备 Transformer 与注意力机制的基本认识会更顺畅
- 课程难度：🌟🌟
- 预计学时：通读约 20 小时，配合动手实验（在每个技术章节自己复现一遍提示）建议 40 小时以上

课程的核心优势是“概念—示例—论文”三位一体。同一个技术先给一句直觉解释，再给出可直接复制的提示词，然后贴出原始论文的实验设置与结果，让人知道这个技巧为什么有效、在什么条件下会失效。相较于零散的博客与短视频，它成体系、有出处、有实验支撑；相较于直接去读论文，它先把术语和动机铺平，阅读门槛低了很多。中英双站内容基本对齐，中文站对大部分技术章节做了翻译，专业名词保留英文括注，便于对照原始文献。

前十来页几乎不需要任何背景知识，半小时就能上手改自己的提示词，成就感来得很直接；越往后越偏研究导向，尤其是思维树、自我一致性、Directional Stimulus Prompting 这类方法，会引用较多论文结论，不习惯读实验表格的话容易卡在细节里。建议把它当成一份“可查阅的路线图”而不是一本线性教材，第一遍通读抓框架，遇到具体任务再回来查对应章节。
