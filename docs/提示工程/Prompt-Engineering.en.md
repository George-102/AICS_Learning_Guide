# Prompt Engineering

## Descriptions

- Offered by: The open source project *Prompt Engineering Guide* initiated by DAIR.AI ([Chinese site](https://www.promptingguide.ai/zh), [English site](https://www.promptingguide.ai/)), continuously updated as an online handbook and backed by a [GitHub repository](https://github.com/dair-ai/Prompt-Engineering-Guide)
- Prerequisites: No machine learning background is required; being able to use any large language model (ChatGPT, Claude, Gemini, Kimi, DeepSeek, and so on) is enough to start. Reading the "Models" and "Research" sections goes more smoothly with basic familiarity with Transformers and attention
- Programming Languages: The guide is mostly prompt text and does not force you to write code; chapters such as RAG, ReAct, and Program-Aided Language Models include Python examples, and the Notebooks section provides runnable OpenAI API code
- Difficulty: 🌟🌟
- Class Hour: About 20 hours to read through, or more than 40 hours including hands-on experimentation (reproducing the prompts in each technique chapter yourself)

The content unfolds in three layers. The first is the introduction: what prompt engineering is, basic concepts, prompt elements (instruction, context, input data, output format), how to tune model settings (temperature, top-p, max length), general tips for designing prompts, and a large set of prompt examples. The second layer is the core, the "Prompting Techniques" section: starting from zero-shot and few-shot prompting and progressing to chain-of-thought (CoT), self-consistency, tree of thoughts (ToT), generated knowledge, prompt chaining, retrieval augmented generation (RAG), the ReAct framework, Reflexion, automatic reasoning and tool-use (ART), automatic prompt engineer (APE), directional stimulus prompting, and program-aided language models. Each technique is presented as motivation, implementation, experimental findings, and limitations. The third layer covers applications and context: the Prompt Hub library of task-organized templates (classification, coding, question answering, reasoning, summarization, information extraction, adversarial prompting), introductions to mainstream models (GPT-4, LLaMA, Gemini, Mistral, Mixtral, Claude, Kimi), risks and misuse (bias, factuality, jailbreaking and prompt injection), and the recently added Agent and context engineering series (Introduction to Agents, Agent Components, Context Engineering, Deep Agents, Function Calling).

Its main strength is the concept-example-paper triad. Each technique gets a one-line intuition, a prompt you can copy directly, and then the experimental setup and results from the original paper, so you learn why the trick works and when it breaks down. Compared with scattered blog posts and short videos, it is systematic, cited, and evidence-backed; compared with going straight to the papers, it lays out the terminology and motivation first, which lowers the barrier a lot. The Chinese and English sites track each other closely, with most technique chapters translated into Chinese and technical terms kept in English parentheses for easy cross-checking against the original literature.

The experience is "easy at the start, self-directed further in". The first dozen pages need no background at all, and within half an hour you are already editing your own prompts, which is immediately rewarding. Further in it becomes more research-oriented: tree of thoughts, self-consistency, and directional stimulus prompting cite a fair number of paper conclusions, and readers unused to experiment tables can get stuck in the details. Treat it as a searchable roadmap rather than a linear textbook: read through once for the framework, then come back to the relevant chapter when you have a real task.

The first pitfall is memorizing templates without understanding the motivation. Copying prompts from the Prompt Hub is satisfying, but they fail as soon as the task changes, because what does the work is the structure (role, task description, context, output constraints) rather than any particular wording. After copying a template, rewrite it yourself and see which parts cannot be moved. The second pitfall is ignoring model differences. Most examples were validated on GPT-3.5 and GPT-4; move to a domestic or small local model and the number of few-shot examples or the trigger words for CoT may behave completely differently, so re-test on your target model. The third pitfall is treating prompting tricks as a universal solution. CoT genuinely helps on reasoning problems, but it does not remove hallucination in factual question answering; when RAG or tool calling is the right tool, switch to it, as the guide itself repeatedly points out. The fourth pitfall is content drift caused by the site's evolution. The newly added Agent and Context Engineering chapters are not fully consistent in terminology and recommendations with the earlier model chapters, and some new pages on the Chinese site still show English titles; when you hit a dated page (say one that only discusses GPT-3), switch to the English site or check the current state of the GitHub repository.

## Course Resources

- Course Website: <https://www.promptingguide.ai/zh> (Chinese), <https://www.promptingguide.ai/> (English)
- Textbooks: No print edition; the site itself is the textbook, and the [GitHub repository](https://github.com/dair-ai/Prompt-Engineering-Guide) contains all Markdown sources and notebooks
- Recordings: The site offers no systematic video course; DAIR.AI Academy sells separate courses, and prompt engineering lectures from universities and communities work well as companions
- Assignments: No standardized assignments; the prompt examples in each chapter, the Prompt Hub templates, and the notebook code serve as practice, and the official site adds two hands-on guides on optimizing prompts and context engineering
