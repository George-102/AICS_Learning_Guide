# 自我革新

结合我本人对自我与外在事物的思考，以及对生活的感悟，我在这里简单提及一些我的生活。如果你不感兴趣可以完全跳过，这只是一个题外专栏。另外如果你也想分享自己的人生经历，欢迎通过邮箱 zhangchaowen@stu.scu.edu.cn联系我。

## 阅读
> _世界上任何书籍都不能带给你好运，但它们能让你悄悄成为你自己。_

阅读我上了大学后才喜欢的爱好，再此之前，我自认为是一个无比普通平凡的人。刚入大学时，一个同乡的学长给我推荐了一些哲学的书籍，我闲来无事便找了电子书来看看，我发现其实读书也没有那么枯燥，随着作者的思想经历各式各样的思想之旅反而是很有趣的。当然，让我真正坚持并热爱读书还是因为我自身的问题。一方面，我需要阅读一些书籍来入门计算机专业，我还记得当时看的是[啊哈 C](http://www.ahacpp.com/)学的C语言；另一方面，上大学后，我很想脱离高中时期的循规守矩，想了解各个专业的知识。我原本是一个非常内向的男孩，我不喜欢上课回答问题，汇报ppt，因为我有改变的原因和动力，我阅读了《被讨厌的勇气》，它让我找到了很大的面对生活的勇气，也让我如今能够不再惧怕失去所谓的面子，活出了真正的自我。同时，因为自我成长的规划，我还阅读过经济学、哲学、文学、天文学、物理学、生物学、语言学等方面的书籍，尽管我对一些领域不感兴趣，例如文学，我很少看这些领域的书籍，但是偶尔找到一本适合自己的也能读完，不过我并不会强迫自己阅读不感兴趣的书籍。

阅读对我最大的好处并非是知识，尽管它们在我的工作生活中很重要，但最重要的是他们重塑了我的世界观和思想。**世界上任何书籍都不能带给你好运，但它们能让你悄悄成为你自己**。如果你非要问一个阅读的好处，我觉得对于每个人最大的好处应该是，让你**活出自我**。人是群居生物，我不喜欢平庸，大事上我很少从众。人天生有从众的趋势，从众当然不是坏事，但久而久之，你的判断力越来越大众化--平凡，如果你再想活出自我的理想，便会难如登天，因为人一旦从事理想，便会遇到困难，大部分人会劝你放弃，而你长期从众而失去判断力，理想便会归于平淡。不过老实说，平凡并非坏事，这个世界大部分人都是普通人，不过总的来说，书籍带来的知识和思想，仍然是我们宝贵的财富。

最后一句话先给你，我们读书是因为，如果我们身边都是平凡而不出众的人，那么我们从小形成的世界观和思想也平平无奇。但是我们通过阅读天才们的书，能够学到他们超越常人的思想，从而应用到生活中，至少我们能真正活出自我的意愿。

## 终身学习

> _人生两大不幸：毕业后不再学习，结婚后不再恋爱_

终身学习的思想存在了上千年，但却是极少人能做到的。尤其是对于计算机行业的人而言，终身学习可谓最重要的准则。计算机领域发展极快，短短几十年，便从每秒仅能运算数千次的电子管巨兽，发展到算力亿万倍于它、无处不在的智能设备。能做到终身学习是很难的，这不仅仅靠你了解其思想，更重要的是将其融入你的个性中。如果你在生活中能做到无意识的持续学习，那你或许已掌握终身学习的诀窍了。

## 习惯即一切

> _卓越不是单一的举动，而是习惯。_

人类做事，大部分其实靠习惯。每天睡懒觉是习惯，早起运动是习惯，定期打扫卫生是习惯，随意扔袜子也是习惯。习惯可以减少我们的思考，从而让我们保持精力充沛。如果你想改善自己，例如每天早睡早起，每天坚持锻炼，你都需要养成一个好习惯。可养成习惯哪有那么容易，以我自己的经历来看，如果我能坚持一个事情一周，我大概率可以养成这个习惯，当然不同习惯形成周期略有波动。我个人养成习惯很简单，如果我想到一件事，例如我想提升认知、亦或是我想完美身材，我就想出一种解决方式，例如读书和锻炼，我会给自己灌输一种思想，**如果一件事对我有利，我就应该爱上它，再此之前，我会装作爱上它**。毕竟*如果你模仿疯子在大街上裸奔，实际上你就是疯子；如果你模仿智者，实际上你就是智者*。最后，我会在开始时简单做这件事，例如锻炼10分钟即可（尽管这可能没有效果），再慢慢形成习惯后，逐步加强。甚至一开始你可以只是下楼去健身房即可，一旦你去了，你潜意识也会告诉你来都来了。相信我，慢慢的，你会变得更加优秀的。不过，一开始不要同时养成太多习惯，人的精力是有限的。
