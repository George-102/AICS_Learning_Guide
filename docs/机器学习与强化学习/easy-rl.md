# Easy RL 强化学习教程

## 课程简介

- 来源：Datawhale 开源社区教程《Easy RL：强化学习教程》（俗称“蘑菇书”，[课程网站](https://datawhalechina.github.io/easy-rl/#/)），作者王琦、杨毅远、江季，已由人民邮电出版社出版纸质版
- 先修要求：熟练使用 Python，了解概率论（随机变量、期望、条件概率）、线性代数与微积分基础，并具备深度学习常识（神经网络、反向传播、梯度下降）
- 编程语言：Python，代码主要基于 PyTorch 与 Gym
- 课程难度：🌟🌟🌟
- 预计学时：通读约 60 小时，配合跑通算法代码与做习题建议 100 小时以上

课程内容分两大部分。第一部分（第 1 至 3 章）打基础，从强化学习与其他机器学习范式的区别讲起，接着是马尔可夫决策过程（MP、MRP、MDP 的层层递进）与表格型方法（Q 表、Sarsa、Q-learning、策略评估与改进）。第二部分（第 4 至 13 章）进入深度强化学习，覆盖免模型预测与控制、深度学习基础、DQN 及其变体、针对连续动作的 DQN、策略梯度、Actor-Critic、DDPG、PPO，以及稀疏奖励、模仿学习等实战问题的处理方法。第二部分各章相对独立，可以按兴趣选读，这为不同目标的读者留出了自由度。

它的核心优势在于中文、成体系、有习题。这本书最初是对李宏毅《深度强化学习》公开课以及周博磊、David Silver 等讲义的整理与再组织，把视频里跳跃性较强的内容补成完整推导，每章末尾附有习题与解答，读起来不像论文综述那样零散。相较于 Sutton 的《强化学习》那种以理论为主、公式密度极高的原典，它更偏工程实现与直觉建立；相较于各类开源 RL 代码库，它不跳步，把每个算法为什么这样设计讲清楚了。业界的说法是这本书“读得下去”，我认为主要得益于它保留了公式推导但配以大量图示与中文解释。

体验上可以感受到明显的陡峭感。前三章读起来轻松，但一到 DQN 部分，目标网络、经验回放、时序差分、重要性采样这些概念会集中涌来，如果深度学习基础不牢，容易在此时掉队。建议在第二部分开始前先复习一遍神经网络训练与梯度下降，把“为什么需要目标网络”这类动机问题想明白，比硬记公式有效得多。

自学的第一个坑是只读不跑。强化学习的很多细节只有跑通代码才能暴露，比如奖励尺度、探索率衰减、采样效率，光看书会觉得已经懂了，实际训练不收敛时才知道问题在哪，建议把每章的 Q-learning、DQN、PPO 至少各跑通一个环境。第二个坑是跳过第一部分直奔深度强化学习。MDP、贝尔曼方程、时序差分是整个学科的共同语言，不扎实就会在后面反复卡壳。第三个坑是对数学符号的畏难。书里的推导确实需要一点耐心，但绝大多数步骤都是期望与梯度的基本操作，遇到卡住的地方回看前两章，或者对照李宏毅的公开课视频，往往一句话就通了。最后提醒一句，这本书写于较早日，部分库版本与代码接口已有变化，跑代码时以官方仓库的最新分支为准。
