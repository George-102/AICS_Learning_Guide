# TOOL-108：LaTeX

## 课程简介

- 来源：LaTeX 官方项目与 CTEX 社区中文资料综合整理（[LaTeX 项目](https://www.latex-project.org/)）
- 先修要求：会用电脑打字即可，无需排版经验；若配合数学课使用，需具备基础的数学符号书写能力
- 编程语言：使用 LaTeX 标记语言编写源文件，用 `pdflatex`、`xelatex` 等引擎编译
- 课程难度：🌟🌟
- 预计学时：基础语法与文档结构 8 小时，能独立排出一篇结构完整的论文另需 20 小时以上

LaTeX 是基于 TeX 的排版系统，TeX 由 Knuth 开发，LaTeX 由 Lamport 在其上封装，两位都是计算机领域举足轻重的人物。不过开发者厉害并不是我们要学它的理由。它和 Word 这类所见即所得的软件最大的区别是分工：你只负责写内容，排版交给系统自动完成。标题层级、图表编号、公式间距、参考文献格式，全都由样式规则统一决定，因此没有任何排版经验的人也能写出排版专业的文章。

这个特点在长文档上体现得最明显。论文写到一百页时，手动调格式的代价会呈指数上升，而 LaTeX 只要开头把样式定义好，后面新增的每一节都会自动遵循同一套规则，编号与目录也会自动更新。数学公式更是它的传统强项，复杂的分式、矩阵、多重下标写起来比任何图形界面都自然。伯克利的 Christos Papadimitriou 有句半开玩笑的评价：每次读到一份 LaTeX 文档，我都会觉得，哇，这一定是对的。

学习路径相对清晰，难点主要在起步。环境配置是第一个拦路虎，本地装 TeX 发行版经常遇到缺宏包与字体问题，用 Overleaf 这样的在线编辑器可以跳过这一步，站内还有大量现成模板可以直接改。之后按顺序读两三篇系统教程，把文档结构、公式、图表、参考文献四块搞明白，剩下的就是在真实写作中查手册。

自学的第一个坑是把 LaTeX 当 Word 用。试图手动调每一处间距，会陷入无穷无尽的 `\vspace` 与 `\hspace` 泥潭；正确的思路是让样式规则去控制，遇到不满意的效果先找对应的宏包而不是打补丁。第二个坑是轻视报错信息。LaTeX 的报错往往定位不准，真正的原因常常在几行之前，比如少了一个 `}` 或环境没有闭合；养成从第一个报错开始查、逐步注释定位的习惯，比盲目搜索报错原文有效。第三个坑是死磕本地环境。配置折腾一整天却还没写过一个字，是最常见的浪费；先用在线工具把内容写出来，需要时再回头解决本地环境。

## 课程资源

- 课程网站：<https://www.latex-project.org/>

## 资源汇总

安装环节可参考《一份简短的安装 LaTeX 的介绍》与《TeX Live 指南》，能把发行版与编辑器配好。写作阶段推荐 Overleaf，站内模板丰富，也免去了环境配置的麻烦。真正掌握它的方式还是写一篇真实的长文档：先从一篇数学课作业起步，再逐步加上图表、交叉引用与参考文献，最后处理封面与附录，走完一轮基本就够用了。
