# ALGO-101：Hello 算法

## 课程简介

- 来源：《Hello 算法》开源教程（[课程网站](https://www.hello-algo.com/)），作者靳宇栋（Krahets），以开源电子书形式发布
- 先修要求：掌握任意一门编程语言的基本语法（变量、循环、函数、递归），对数组和链表有直观认识即可
- 编程语言：示例覆盖 Java、C++、Python、Go、JavaScript、TypeScript、C#、Rust、Swift、Dart、Zig 等十余种语言，同一段逻辑提供多语言版本
- 课程难度：🌟🌟
- 预计学时：通读约 40 小时，配合动手实现与刷题建议 60 小时以上

全书分复杂度分析、数据结构、算法三个大模块。数据结构部分讲数组与链表、栈与队列、哈希表、二叉树、堆、图，算法部分讲搜索、排序、分治、回溯、动态规划与贪心。每章按“定义、实现、应用场景”的顺序展开，先给知识地图，再逐个结构拆解，最后用算法范式收束，适合作为数据结构与算法的第一本书。

它最突出的特点是动画图解与可运行代码。每个关键操作都有逐帧动画，把数据在内存中的变化过程演给你看，比静态配图更容易建立直觉；所有示例代码可以直接运行，注释详细，并且同一段逻辑给出了十多种语言的实现，方便用自己熟悉的语言对照阅读。相较于《算法导论》这类偏理论与证明的教材，它更像一张能边走边动手的路线图；相较于各类刷题笔记，它成体系、有取舍，不会一上来就堆技巧。

学习曲线确实平滑：章节短、图多、文字少，一天翻一章不容易卡住，对零基础读者非常友好。但也要清楚它的定位是入门，进阶结构如红黑树、B 树、并查集、线段树没有展开，复杂度分析的数学推导偏浅，动态规划也只覆盖经典模型。读完能看懂大部分题解，却不足以直接应付竞赛或大厂算法面试的难题，后续还需要另一门更硬的课程接续。

自学的第一个坑是把“看懂动画”当成“掌握了”。动画直观到会产生错觉，真正动手时才会发现边界条件、数组下标、递归终止条件一个都不能少，建议每看完一节就合上书自己实现一遍。第二个坑是缺少配套练习。这本书讲原理，不提供足量题目，不刷题很难形成手感，建议同步用 LeetCode 按专题补题。第三个坑是多语言示例带来的干扰。入门阶段请盯住一门语言看，别在多语言之间来回对照，否则注意力会跑到语法差异上，而不是算法本身。
