# ALGO-101: Hello Algo

## Descriptions

- Offered by: The open source tutorial *Hello Algo* ([course website](https://www.hello-algo.com/en/)), written by Jin Yudong (Krahets) and released as an open source e-book
- Prerequisites: Basic syntax of any programming language (variables, loops, functions, recursion), plus an intuitive grasp of arrays and linked lists
- Programming Languages: Examples cover more than ten languages, including Java, C++, Python, Go, JavaScript, TypeScript, C#, Rust, Swift, Dart, and Zig, with every piece of logic provided in multiple languages
- Difficulty: 🌟🌟
- Class Hour: About 40 hours to read through, or more than 60 hours including hands-on implementation and practice problems

The book has three major parts: complexity analysis, data structures, and algorithms. The data structure part covers arrays and linked lists, stacks and queues, hash tables, binary trees, heaps, and graphs, while the algorithm part covers searching, sorting, divide and conquer, backtracking, dynamic programming, and greedy algorithms. Each chapter follows a "definition, implementation, use cases" order: a knowledge map first, then each structure dismantled one by one, and finally the algorithmic paradigms tying it together. It works well as your first book on the subject.

Its most distinctive feature is animated illustrations with runnable code. Every key operation has a frame-by-frame animation that walks you through how the data changes in memory, which builds intuition more easily than static diagrams. All example code runs as-is, is heavily commented, and the same logic is given in a dozen languages so you can read along in the one you know. Compared with theory- and proof-heavy texts such as *Introduction to Algorithms*, it reads more like a route you can walk while typing; compared with scattered interview notes, it is systematic and selective instead of piling up tricks from page one.

The learning curve really is smooth: short chapters, plenty of figures, little prose, and a chapter a day is rarely a struggle. It is very friendly to readers with no prior background. But be clear about its scope. It is an introductory book: advanced structures such as red-black trees, B-trees, union-find, and segment trees are not covered, complexity derivations stay shallow, and dynamic programming only reaches the classic models. After finishing it you can read most editorials, but it is not enough by itself for contests or the hard half of algorithm interviews at large companies, and another more demanding course should follow.

The first pitfall is mistaking understanding the animation for having mastered the topic. Animations are intuitive enough to create an illusion, and only when you actually write the code do you find that boundary conditions, array indices, and recursion base cases cannot be skipped. Close the book and implement each section yourself. The second pitfall is the lack of a companion exercise set. The book explains principles and does not supply enough problems, so pair it with LeetCode problems organized by topic, otherwise fluency never forms. The third pitfall is distraction from multi-language examples. Stick to one language at the beginner stage instead of cross-referencing several, or your attention drifts to syntax differences rather than the algorithm itself.
